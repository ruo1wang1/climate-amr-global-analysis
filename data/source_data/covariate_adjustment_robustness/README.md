# Covariate-adjustment robustness source data

This folder contains derived source data for the four-specification covariate-adjustment robustness analysis.

Files in `01_csv/` include:
- model-level summaries
- climate-term comparison tables
- smooth-statistics and retention summaries
- shape-similarity outputs
- linear VIF values
- top-covariate manifests
- curve-plot data

The workbook in `02_workbook/` combines the source-data tables for this analysis.
