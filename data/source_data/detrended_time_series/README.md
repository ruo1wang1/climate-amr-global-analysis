# Analysis of climate-AMR associations using detrended time series

This folder contains derived source data for the detrended time-series robustness analysis.

Files in `01_csv/` include:
- overall summary metrics
- shape-consistency summaries
- common-detrending diagnostics
- robustness summaries
- model manifests

The workbook in `02_workbook/` combines these tables into a single release file.
